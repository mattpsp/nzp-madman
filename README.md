# NZ:P: MADMAN

nz:p madman is a personal fork of nazi zombies portable that i'm working on by myself.

i've always enjoyed playing nz:p, but i wanted to try making my own version of it that would actually be challenging. the main idea is to make the zombies more threatening, especially in the earlier rounds, while still keeping the game fun.

right now it's pretty simple, just more zombies and increased health, but i plan on adding a lot more stuff over time. things like changes to zombie behavior, random events, and hopefully a system that adapts to how you play.

i don't want to make the game impossible or unfair, i just want surviving to actually feel difficult and rewarding.

this is my first time working on something like this, so i'm still figuring things out as i go.

**current version:** v0.1 (early prototype)
